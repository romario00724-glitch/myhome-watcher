# Монітор myhome.ge → Telegram

Кожні ~10 хвилин перевіряє пошук на myhome.ge (лише оголошення від власників) і надсилає в Telegram тільки **нові** оголошення: фото, ціна, район, телефон (якщо є), посилання. Агентів, які прикидаються власниками, позначає ⚠️. Під кожним оголошенням — кнопка «📢 Додати в канал», яка публікує його у ваш Telegram-канал.

Файли: `watcher.py` — скрипт, `searches.txt` — посилання на пошук, `channel_template.txt` — шаблон поста для каналу, `requirements.txt` — залежності, `.github/workflows/watch.yml` — автозапуск на GitHub.

---

## 1. Telegram-бот (5 хвилин)

1. У Telegram відкрийте **@BotFather** → `/newbot` → придумайте назву. Він дасть **токен** виду `7123456789:AAH...`.
2. Той, хто отримуватиме оголошення, відкриває свого бота й тисне **Start**.
   Хочете отримувати обоє — створіть групу й додайте туди бота.
3. Дізнайтеся **chat_id**: відкрийте в браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `"chat":{"id":123456789`.
   (Або `python watcher.py --chat-id`, коли токен уже вказаний.) У групи id від'ємний, з мінусом.
   Кілька чатів — через кому: `123456789,-100987654321`.

## 2. Посилання з myhome.ge

1. На myhome.ge оберіть: **Аренда** (або **Продажа**) → **Квартира** → **Батуми**, за бажанням район, ціну, кімнати, і увімкніть **Собственник**.
2. Натисніть «Поиск» і скопіюйте адресу з адресного рядка. У ній мають бути `deal_types=` і `cities=`.
3. Вставте в `searches.txt` замість `ВСТАВТЕ_СЮДИ_ПОСИЛАННЯ`. Можна кілька рядків, наприклад оренда й продаж окремо:
   ```
   Оренда | https://www.myhome.ge/...?deal_types=2&...&cities=...
   Продаж | https://www.myhome.ge/...?deal_types=1&...&cities=...
   ```

Фільтр «Власник» скрипт додає сам. Новий рядок у `searches.txt` при першому запуску тихо «запам'ятовує» поточні оголошення, щоб не засипати чат старими.

## 3а. Перевірка на своєму комп'ютері

Потрібен Python 3.10+ (python.org). У папці з файлами:

```
pip install -r requirements.txt
```

Токен і chat_id або впишіть угорі `watcher.py`, або задайте в терміналі:

- Mac/Linux: `export TELEGRAM_BOT_TOKEN="..."` і `export TELEGRAM_CHAT_ID="..."`
- Windows (PowerShell): `$env:TELEGRAM_BOT_TOKEN="..."` і `$env:TELEGRAM_CHAT_ID="..."`

Далі:

```
python watcher.py --test    # покаже 3 свіжі оголошення і надішле 1 тестове в Telegram
python watcher.py           # стежить, поки комп'ютер увімкнений (Ctrl+C — зупинити)
```

У `--test` перевірте два рядки:
- «міста: …» — там має бути Батумі;
- «Кількість оголошень автора на сайті: N (поле …) ✅». Якщо замість цього написано «не знайдено», запустіть `python watcher.py --dump` і надішліть файли `dump_list.json` і `dump_detail.json` — по них видно, як сайт називає це поле.

## 3б. Цілодобово й безкоштовно на GitHub

1. github.com → **New repository** → **Public** → Create.
2. «uploading an existing file» → перетягніть `watcher.py`, `searches.txt`, `requirements.txt`, `README.md` → **Commit**.
3. **Add file → Create new file**, назва: `.github/workflows/watch.yml`, вставте вміст однойменного файлу → **Commit**.
4. **Settings → Secrets and variables → Actions → New repository secret**: додайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
5. **Actions → myhome-watcher → Run workflow**. Перший запуск надішле «✅ Стежу за пошуком…», далі нові оголошення приходитимуть самі.

Нотатки:
- У публічному репозиторії запуски безкоштовні без обмежень. Видно в ньому лише код, посилання на пошук і `state.json` (номери вже побачених оголошень); токен захований у Secrets.
- Приватний репозиторій теж можна, але там 2000 безкоштовних хвилин на місяць — поставте у `watch.yml` інтервал `*/30 * * * *`.
- GitHub запускає розклад із затримкою в кілька хвилин — це нормально.
- Змінити пошук можна прямо на сайті GitHub: відкрийте `searches.txt` → олівець → збережіть.

## Кнопка «📢 Додати в канал»

Під кожним новим оголошенням бот ставить кнопку. Натиснули — бот сам бере з myhome.ge фото (до 10, альбомом) і опис та публікує пост у ваш канал за шаблоном з `channel_template.txt`. Кнопка під оголошенням стане «✅ В каналі» з посиланням на пост; повторне натискання вдруге не опублікує.

Налаштування (один раз):

1. Додайте бота в канал **адміністратором** з правом «Публікація повідомлень».
2. Дізнайтеся id каналу: для публічного — просто `@назва_каналу`; для приватного — перешліть будь-який пост каналу боту **@userinfobot** (або запустіть `python watcher.py --chat-id` після того, як додали бота в канал) — буде число виду `-1001234567890`.
3. GitHub → **Settings → Secrets and variables → Actions → New repository secret**: `TELEGRAM_CHANNEL_ID` = `@назва_каналу`, посилання на канал (`https://t.me/назва_каналу`) або `-100...`. (Локально — `"channel_id": "..."` у `telegram.json`.)

Без `TELEGRAM_CHANNEL_ID` кнопки просто немає — усе працює як раніше.

**Коли з'явиться пост.** Натискання кнопки Telegram тримає недовго, тому на GitHub кожен запуск після перевірки оголошень ще ~9 хвилин слухає кнопки — аж до наступного запуску. Кнопка одразу стає «⏳ Публікую…», а за ~20–30 секунд пост з'являється в каналі й кнопка змінюється на «✅ В каналі». Між запусками є пауза секунд на 30–60; натискання в цей момент підхопить наступний запуск. Не запускайте бота одночасно ще й на своєму комп'ютері — вони «перехоплюватимуть» натискання один в одного.

**Шаблон поста** — файл `channel_template.txt` (редагується прямо на GitHub). Можна писати будь-який текст, емодзі, свої контакти й хештеги, а також `<b>жирний</b>`, `<i>курсив</i>`, `<a href="https://t.me/нік">посилання</a>`. Замість `{назв}` підставляються дані оголошення:

| | |
|---|---|
| `{headline}` | «Уютная 2-комнатная квартира (1+1) в Старом Батуми» — пише ШІ; без ШІ — «Уютная 2-комнатная квартира (1+1), Старый Батуми» |
| `{points}` | рядки «✔️ Срок: …», «✔️ Состояние: …» з опису власника — пише ШІ; без ШІ — «✔️ опис власника» |
| `{terms}` | «(договор, оплата за первый и последний месяцы)», якщо власник про це пише — ШІ; без ШІ порожньо |
| `{rooms_title}` | «2-комнатная квартира (1+1)» або «квартира-студия» |
| `{plan}` | «1+1 (отдельная спальня + кухня-гостиная)» |
| `{price_main}` · `{price_usd}` · `{price_gel}` · `{price}` | «450$» (якщо доларової ціни немає — «1 215 ₾») · «450$» · «1 215 ₾» · «1 215 ₾ · $450» |
| `{area}` · `{floor_full}` | «41» · «1/5» |
| `{rooms}` `{bedrooms}` `{floor}` `{floors}` · `{facts}` | окремі числа · «41 м² · кімнат: 2 · спалень: 1 · поверх 1/5» |
| `{place}` · `{district}` · `{address}` · `{city}` | «Квариати, шоссе Аэропорта» · район · адреса · місто |
| `{bedrooms_tag}` `{plan_tag}` `{district_tag}` `{city_tag}` `{district_rent_tag}` | `#1спальня` `#1плюс1` `#квариати` `#батуми` `#сдамквартируКвариати` |
| `{title}` · `{deal}` · `{deal_tag}` | заголовок з сайту · «Оренда» · `#оренда` |
| `{description}` | опис власника одним абзацом, до `CHANNEL_DESCRIPTION_MAX` символів (телефони з нього прибираються, див. `CHANNEL_HIDE_PHONES`) |
| `{owner_phone}` · `{link}` · `{id}` | телефон власника · посилання на myhome.ge · номер оголошення |

Шаблон у репозиторії вже зроблений у стилі каналу «Аренда Батуми 🏢 Batumi Rent» з контактом Ольги. Рядок, у якому всі `{назви}` виявилися порожніми (наприклад, поверх не вказано), пропускається. Підпис до фото в Telegram — максимум 1024 символи, тому довгий опис бот акуратно обріже.

**Текст від ШІ (OpenAI).** Щоб заголовок, пункти «✔️ Срок / Состояние / …» та умови оплати писалися «по-людськи» з опису власника (з перекладом з грузинської й правильними відмінками районів), додайте секрет `OPENAI_API_KEY` (ключ з platform.openai.com → API keys). Локально — `"openai_key": "sk-..."` у `telegram.json`. Модель за замовчуванням — `gpt-5-mini` (частки цента за пост); іншу можна вказати в **Settings → Secrets and variables → Actions → Variables** змінною `OPENAI_MODEL`. ШІ пише тільки те, що є в оголошенні; площа, поверх, ціна, хештеги й контакт Ольги завжди беруться з даних і шаблону. Якщо OpenAI не відповість, пост усе одно вийде за звичайним шаблоном, а в чат прийде попередження. Інструкція для ШІ — `AI_PROMPT` у `watcher.py`.

**Переклад у чаті.** З тим самим `OPENAI_API_KEY` бот перекладає російською опис і адресу оголошень, написаних грузинською чи англійською (російськомовні не чіпає — це безкоштовно й швидко). Вимкнути — `TRANSLATE_ALERTS = False` угорі `watcher.py`. Адреса в пості для каналу теж перекладається.

Перевірити шаблон, не публікуючи в канал: `python watcher.py --preview 12345678` (номер оголошення — з посилання на myhome.ge) — пост прийде у ваш робочий чат. Опублікувати вручну: `python watcher.py --post 12345678`.

## Що означають позначки

- **✅ У автора 1 оголошення на myhome.ge** / **⚠️ У автора 25 оголошень на myhome.ge** — скільки оголошень у цього автора на всьому сайті (береться з картки оголошення, працює з першого дня). З `AGENT_THRESHOLD` і більше — це агент під виглядом власника або інвестор із кількома квартирами (теж цікавий контакт).
- **⚠️ Цей автор або телефон уже трапився в N оголошеннях** — власна база скрипта. З'являється, коли вона знає більше за сайт (наприклад, той самий телефон на кількох акаунтах) або коли сайт лічильник не віддав.
- **⚠️ В описі згадується агенція або комісія.**
- **✍️ Пише, що без посередників** — лише підказка, агенти теж так пишуть.

Телефон на myhome.ge часто прихований (`599404***`). Якщо власник вписав номер в опис, скрипт покаже його повністю.

## Налаштування (вгорі `watcher.py`)

- `AGENT_THRESHOLD = 3` — з якої кількості оголошень автора ставити ⚠️.
- `SKIP_SUSPECTED_AGENTS = False` — `True`, щоб таких узагалі не надсилати (рахується більше з двох чисел: на сайті чи в базі скрипта).
- `LANG = "ru"` — мова назв і посилань (`ru` / `en` / `ka`).
- `MAX_ALERTS_PER_RUN = 25` — максимум повідомлень за одну перевірку.
- `CHANNEL_MAX_PHOTOS = 10` — скільки фото брати в пост каналу.
- `CHANNEL_HIDE_PHONES = True` — прибирати телефони власника з опису в каналі (`False` — лишати).
- `CHANNEL_DESCRIPTION_MAX = 350` — скільки символів опису власника брати в пост (`0` — скільки влізе в підпис).

## Якщо щось не так

- **HTTP 403 / «відповідь не JSON»** — myhome.ge прийняв запит за бота. Перевірте, що встановлено `curl_cffi`. Якщо на GitHub це повторюється годину поспіль, бот сам напише в Telegram.
- **«немає фільтра міста»** — у посиланні немає `cities=`. Застосуйте фільтри на сайті ще раз і скопіюйте адресу.
- **У Actions помилка push (403)** — Settings → Actions → General → Workflow permissions → **Read and write**.
- **Почати з нуля** — `python watcher.py --reset` (або видаліть `state.json` на GitHub).
- Скрипт працює через внутрішній API сайту. Якщо myhome.ge його змінить, скрипт доведеться підправити.
